# Ascendia Android Demo

Ascendia turns real-world discipline into an original anime-fantasy rank progression experience. The visual identity is Cosmic Horizon: cinematic art, celestial environments, luminous blue and violet detail, and a carefully designed RPG interface.

## Current stage

Step 1 establishes the Expo and React Native foundation, strict TypeScript, navigation across five primary destinations, startup configuration, and the first shared theme tokens. Route content is deliberately temporary foundation copy, not the finished five-screen experience.

Step 2 adds reusable Cosmic Horizon visual primitives, original app-ready art and the asset pipeline. Subsequent steps add complete screen design and local quest/progression behavior.

## Requirements

- Node.js 22.13 or newer for Expo SDK 57.
- npm, currently defined by the package scripts.
- Android Studio with Android SDK and emulator, or a physical Android device with USB debugging.
- Java/JDK compatible with the Expo-generated Android Gradle Plugin when running a native Gradle build.

## Commands

Run these in a network-enabled development environment:

```sh
npm install
npm run start
npm run android
npm run typecheck
npm run lint
npm test
npm run expo:check
npm run doctor
```

The repository had no package manager or lockfile at first audit. A `package-lock.json` must be generated by `npm install` and committed. Dependency installation and scripts are not yet verified in this GitHub-only session.

## Platform and navigation

Android is the demo target. Expo Router provides the five primary destinations: Home, Quests, Player, Adventures and Profile. The root layout uses safe-area support and a light status bar over a dark surface. Shared SVG tab icons replace emoji.

The starter route content is a foundation placeholder. Full Cosmic Horizon screens are not yet implemented. The theme uses platform serif, sans-serif and monospace families until font files are approved and their licensing is confirmed.

## Product boundaries

No inventory, loot, equippable gear, equipment statistics, combat, backend, login, cloud sync, AI service, social system or subscription is part of this foundation. A navigation placeholder does not imply a feature exists.

See `AGENTS.md`, `ASCENDIA_DEMO_BUILD_STEPS.md`, and `docs/` for product rules, design direction, asset status, architecture, outstanding decisions and build evidence.
