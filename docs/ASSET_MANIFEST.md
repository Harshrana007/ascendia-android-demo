## Minimum visual asset requests for implementation

1. Home environment and approved hero artwork.
2. Quests environment or background crop, with adequate readable contrast.
3. Player environment and an initial approved class/presentation character.
4. Adventures environment and a small set of location images.
5. Profile environment/avatar crop.
6. Rank crystal and rank emblems.
7. Six attribute icons and consistent quest-type icons.
8. Font files only after licensing and integration compatibility are confirmed.
9. Character evolution mappings for the available assets.

## Asset rules

- Preserve supplied reference files untouched.
- Record dimensions, format, crop, purpose, provenance, licensing status and whether each production asset is temporary or approved.
- Do not claim a crop is transparent if it has a solid background.
- Avoid copying protected anime characters, logos or proprietary interfaces. Commission or use authorized original art.
- Prepare app-optimized derivatives separately from immutable reference images.
- Do not create 96 polished character illustrations in the foundation step.
